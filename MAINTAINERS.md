## Wanted

AgentFuse has one maintainer, and wants more, especially from organizations
not already represented. Areas where help would make the biggest difference:

- credential revocation for AWS IAM, GCP and GitHub,
- dependency-aware containment,
- pattern-based trips,
- PagerDuty and OpenTelemetry events.

If you're interested, start with an issue labelled `good first issue` or
`help wanted`, or open an issue to say what you'd like to work on.
